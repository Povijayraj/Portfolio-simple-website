# Personal Portfolio Website

A simple and responsive personal portfolio website built using **HTML5** and **CSS3**. This project is designed to showcase my profile, basic information, and contact details in a clean and professional layout. The website is lightweight, user-friendly, and suitable for beginners learning front-end web development.


## Features
- Responsive design for desktop and mobile devices
- Simple and clean user interface
- Home page with introduction section
- Contact page with contact information
- Smooth navigation between pages
- Organized HTML and CSS structure

## Technologies Used
- HTML5
- CSS3
